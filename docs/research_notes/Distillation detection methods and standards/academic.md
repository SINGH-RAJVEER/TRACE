# Academic methods for detecting model extraction through teacher APIs

Research cutoff: 2026-11-05. Dates below distinguish first public preprints from verified conference publication. This note evaluates published mechanisms and their assumptions; it does not claim that TRACE already implements them.

## Which established detectors have useful mechanisms, and what did their experiments establish?

### Takeaway

Stateful detection has established research precedents. Most early methods assume image classification and distinguish synthetic, augmented, or out-of-distribution queries from ordinary task inputs; their published accuracy and false-positive results do not establish protection for open-ended LLM distillation. [PRADA](https://arxiv.org/html/1805.02628v3), [VarDetect](https://arxiv.org/pdf/2107.05166), [SEAT](https://people.eecs.berkeley.edu/~daw/papers/seat-aisec21.pdf)

### Cited findings

- PRADA, Juuti et al., first public 2018-05-07, EuroS&P 2019, keeps client query history and examines the distribution of nearest historical distances, with comparisons conditioned on predicted classes. It uses Shapiro-Wilk normality statistics after removing distant outliers and starts after more than 100 retained distances. The paper uses Euclidean image distance and a chosen detection threshold. It measures attack detection, queries before detection, and false alarms on tested benign sequences. Its headline zero-false-positive result belongs to those experiments. A reference implementation exists. [Paper](https://arxiv.org/html/1805.02628v3), [author repository](https://github.com/SSGAalto/prada-protecting-against-dnn-model-stealing-attacks)
- VarDetect, Pal et al., public preprint 2021-07-12, trains a modified variational autoencoder to place confidential training inputs and constructed noisy outliers in different latent regions. It compares each user's rolling query distribution with training-data latent distributions using multi-kernel MMD. Experiments use a 100-query buffer and include Fashion-MNIST, traffic signs, and SVHN. The paper measures alarms and substitute-model accuracy and adversarial transferability after defense. Adaptive evaluations include benign-query dilution and white-box iterative gradient perturbation against the encoder. These are particular tested adaptations, not a universal adaptive-security result. Deployment requires training data, a trained encoder, per-user history, and stable user identification. [Paper](https://arxiv.org/pdf/2107.05166), [preliminary author code](https://github.com/vardetect/vardetect)
- SEAT, Zhang, Chen, and Wagner, AISec 2021-11-15, trains an adversarially robust similarity encoder. An account triggers after enough query pairs are similar in the learned space. Its premise is that augmentation-based extraction repeatedly modifies existing examples. It evaluates Jacobian-based augmentation, data-free extraction, query blinding, and query filtering, and reports increased account costs against tested adaptive attackers. The cost argument assumes detected accounts can be cancelled and new accounts are costly. It is an image-classification study, with a reported benign-query FPR of 0.01%, not a demonstrated LLM account-level error rate. A widely surfaced GitHub implementation explicitly says it is unofficial. [Author-hosted paper](https://people.eecs.berkeley.edu/~daw/papers/seat-aisec21.pdf), [unofficial implementation notice](https://github.com/grasses/SEAT)
- HODA, Sadeghzadeh et al., first public 2021-06-21, defines input hardness through when its predicted class stabilizes across saved training checkpoints. It compares the histogram of a user's input hardness with a benign histogram. Its scope is data-limited extraction using synthetic or semantically related out-of-distribution samples, with experiments reporting detection from sequences of 100 samples. It needs intermediate target-training classifiers and a suitable benign reference, making direct use difficult for a gateway that only proxies a third-party teacher. [Preprint](https://arxiv.org/abs/2106.11424), [full method](https://openreview.net/pdf?id=eDjxhFbaWX)
- FDINet, Yao et al., first public 2023-06-20, computes feature distortion relative to training anchors, trains a binary detector, and links possible colluders through similar distortion patterns. Its experiments cover six attacks on four vision datasets and include feature correction and benign dummy-query adaptations. The paper explicitly leaves language-model extension to future work. It reports added query costs under dilution; that supports a measured cost increase for the tested setting, not elimination of extraction. [Paper](https://arxiv.org/html/2306.11338v1)
- Kesarwani et al., first public 2017-11-20, estimate extraction progress with a local decision tree trained from user query-response pairs and information gain against a validation set, or compact feature-space coverage summaries. They consider individual users and colluding groups and evaluate BigML decision-tree APIs. The coverage method depends on decision-tree leaves and continuous feature ranges. This is a precedent for exposure estimation, not evidence that arbitrary semantic breadth proves unauthorized LLM training. [Paper](https://arxiv.org/html/1711.07221)
- ActiveThief, AAAI 2020, studies extraction using active learning over unannotated public inputs. Its existence matters when defining threat coverage: extraction need not rely on synthetic near-duplicates. [Author-hosted paper](https://www.csa.iisc.ac.in/~vg/papers/aaai2020/aaai2020.pdf)
- ATOM, public 2025-03-20, KDD 2025, combines sequential modeling, reinforcement learning, and graph k-core representations for graph-neural-network extraction. It is evidence for stateful graph extraction detection, not validated transfer of reinforcement-learning defenses to LLM APIs. [Preprint](https://arxiv.org/abs/2503.16693), [conference record](https://doi.org/10.1145/3711896.3736848)

### Inferences

- A semantic nearest-neighbor component is a reasonable LLM adaptation for repeated variants, paraphrase sweeps, and local exploration. It needs its own benign baselines for editing, retries, tutoring, and batch processing. SEAT's image results do not qualify that adaptation.
- Coverage, low redundancy, diversity, uncertainty selection, or structured outputs should enter an evidence model as observed behavior. Each can occur during ordinary evaluation or automation. They do not reveal whether the recipient later trains a student.
- HODA and target-feature FDINet are poor first choices when TRACE cannot access teacher checkpoints or internal activations. An independent text encoder reduces that dependency but changes the scientific method being claimed.

### Gaps

- These classic papers do not provide validated thresholds for TRACE's account populations, tasks, or LLM prompt distributions.
- No direct primary result found here establishes that a generic active-learning or topic-coverage score alone separates authorized LLM evaluation from unauthorized distillation.

## Which recent LLM traffic and campaign detectors are directly relevant?

### Takeaway

Two 2026 preprints provide more direct candidates: benign-calibrated semantic MMD for traffic windows, and cross-account coordination analysis. A separate session-classifier report is useful as a design example, but its detection results come from generated data. [Semantic MMD](https://arxiv.org/abs/2606.05725), [distributed query monitoring](https://arxiv.org/abs/2610.13083), [session classification](https://arxiv.org/abs/2609.38239)

### Cited findings

- Liu, Guo, and Dong, public 2026-06-04, embed text with normalized BGE-small representations and compare a traffic window against benign reference batches using multi-bandwidth RBF MMD. They calibrate thresholds only from benign comparisons. The default window contains 1,500 queries, averages 20 reference comparisons, and uses a 95th-percentile threshold from 1,000 benign calibration samples. Across 14 attacker-normal pairs and three seeds, Table 1 reports 0.3% benign-window FPR, 100% pure-attacker TPR, and 59% TPR at 5% contamination. Attacks include task extraction involving BERT as well as generative LLM scenarios. These are dataset-based window experiments, not production campaign confirmation. The method labels windows, not individual requests. Its threshold uses unaveraged calibration comparisons while the incoming score averages reference comparisons, so the nominal percentile should not be treated as a formal deployment FPR guarantee. [Paper](https://arxiv.org/html/2606.05725v1), [code and data](https://github.com/LabRAI/mmd-llm-mea-detection)
- Khilar, public 2026-10-09, turns each account's text embeddings into random-Fourier topic summaries, whitens against history, and selects coordinated groups spectrally. Centering and removing diagonal self-concentration, called hollowing, helps distinguish jointly aligned deviations from merely topical individuals. One frozen evaluation uses 17 later WildChat weeks. It reports 0.86 to 1.00 weekly detection for naive dataset campaigns and 0.50 to 0.96 for padded campaigns with hollowed selection. Real false alarms sometimes exceed the nominal 1%. Benign evaluation sweeps trigger the same detector. No deployable detector emerges at colluder shares of 2.5% or below; slow calibration poisoning and real-user relays remain failure cases. The study trains small students, but its measured capability frontier is testbed-specific. The authors explicitly leave the anytime-valid alarm delay for hollowed selection unmeasured. This is a recent independent preprint, not an established production defense. [Paper](https://arxiv.org/html/2610.13083v1), [released experiments](https://github.com/nssprogrammer/query-monitoring)
- Lee, public technical report 2026-09-29, trains gradient-boosted user-session classifiers on a structural-causal-model-generated dataset. Inputs include trailing seven-day account aggregates, requests, perplexity, structure entropy, domain-coverage changes, and cross-account infrastructure signals. It separates operational, investigated, and oracle labels. The reported binary AUPRC changes from 0.993 against oracle labels to 0.313 against operational labels, but both are evaluations of synthetic sessions. The report acknowledges that its generator encodes heuristics the detector then learns, and that real traffic is likely harder. It excludes some generator flags because they approximate oracle labels. This demonstrates a prototype and label-observability problem; it does not validate actual provider campaign detection. [Report](https://arxiv.org/html/2609.38239v1), [released dataset](https://huggingface.co/datasets/DaoistDurian/lang-adversarial-inference-01)

### Inferences

- If TRACE already has MMD shadows, adding another global MMD score is not the main research advance. The distinct components worth examining are task- and cohort-conditioned benign references, time-valid evidence accumulation, learned query similarity, and cross-account directional coordination.
- A campaign classifier should learn from independently established campaign labels and retain difficult benign sessions. Training on generated actors whose defining features are also the detector inputs risks measuring whether the classifier reconstructs the simulator.
- The strongest practical next step is to reproduce one defined traffic detector and its negative controls before combining many weak signals. Otherwise a more complicated detector may only learn topic, dataset source, or automation.

### Gaps

- No verified primary evidence found here qualifies these recent preprints against TRACE's exact workloads or reports a production-calibrated detection rate under arbitrary benign drift.
- Query-only monitoring cannot observe student training directly. Infrastructure linkage and confirmed enforcement outcomes answer different questions and should be reported separately.

## What statistical extensions and fundamental limits should guide implementation?

### Takeaway

There are rigorous tools for conditional comparisons and continuous monitoring, but their statistical nulls must match the application. Distillation attribution after release is a separate task, and observational defenses have formal and empirical limits. [Conditional testing](https://arxiv.org/abs/2506.03898), [sequential testing](https://arxiv.org/html/2112.09162v6), [observational limits](https://eprint.iacr.org/2022/1039.pdf)

### Cited findings

- Shekhar and Ramdas, first public 2021-12-16, develop nonparametric two-sample testing by betting, including a sequential MMD instantiation. Evidence accumulates as a betting wealth process and crosses a threshold. The framework supports optional stopping under stated null and predictability assumptions. The current manuscript acknowledges an error in the earlier expected-stopping-time justification and links a correction. This is a statistics result, not a measured LLM extraction defense. [Current paper](https://arxiv.org/html/2112.09162v6), [author correction](https://github.com/sshekhar17/nonparametric-testing-by-betting/blob/main/Correction.pdf)
- Podkopaev et al., ICML 2023, show why repeatedly applying ordinary batch tests inflates false alarms and provide time-uniform kernel independence tests. Their nonstationary guarantees have explicit assumptions; they do not permit arbitrary simultaneous drift of all observed variables. [Proceedings paper](https://proceedings.mlr.press/v202/podkopaev23a/podkopaev23a.pdf)
- Massiani et al., public 2025-06-04, revised 2025-10-31 under the title "Kernel conditional tests from learning-theoretic bounds," derive tests of conditional expectations and conditional distributions using kernel ridge regression, kernel mean embeddings, and confidence bounds. Some guarantees cover online, non-independent observations under specified assumptions. Process monitoring and dynamical-system comparisons are demonstrations. This supports considering covariate-conditioned tests, but provides no published model-extraction TPR or LLM-specific threshold. [Current paper](https://arxiv.org/abs/2506.03898), [author implementation](https://github.com/Data-Science-in-Mechanical-Engineering/conditional-test)
- Karchmer, SaTML 2023, formalizes observational model-extraction defenses that inspect query distributions. Under a subexponential Learning Parity with Noise assumption, efficient defenses for polynomial-size decision-tree models cannot simultaneously satisfy the paper's completeness and soundness requirements. Natural covert-learning attacks establish the result. Its scope is a formal model and specified concept classes; it is not a theorem that every practical LLM campaign is undetectable. [Paper dated 2023-01-03](https://eprint.iacr.org/2022/1039.pdf), [author publication list](https://www.arikarchmer.com/)
- Chen, Carlini, and Wagner, first public 2019-07-12, SPAI 2020, show query blinding can evade PRADA. Their experiment concerns adversarial-example generation on an image classifier, not LLM distillation. It demonstrates that harmless input transformations can break distance assumptions while preserving useful oracle outputs. [Author-hosted paper](https://people.eecs.berkeley.edu/~daw/papers/stateful-spai20.pdf)
- Chen and Du, public 2026-10-08, CCS 2026 poster scheduled after this research cutoff, audit whether a suspect model was distilled. They train distilled and independent shadows and compare suspect likelihoods of teacher reasoning traces. The audit assumes identifiable training queries and examines Qwen2.5-7B teacher and Llama-3.2-3B suspects. Its preliminary perfect TPR at significance 0.02 belongs to that setup. It is post-hoc model provenance inference, not an online API traffic detector. Watermarking and fingerprinting likewise need their own attribution experiment and access to text or a suspect model. They cannot by themselves establish that a currently active API client is training a student. [Poster](https://arxiv.org/html/2610.12137v1)

### Inferences

- Recommended first candidate: retain TRACE's existing MMD infrastructure if present, then compare incoming behavior with benign sessions matched by task, endpoint, time, language, and known workflow. Treat this as an application-specific extension; task matching is not automatically the same method as formal conditional MMD.
- Recommended second candidate: add a sequence detector for near-duplicate and paraphrase families. Keep this separate from broad dataset-like coverage because the two target different attacker strategies.
- Recommended third candidate: add cross-account coordination summaries with centered, normalized similarity. This requires enough accounts and reliable historical references. It should produce investigation evidence with matched benign evaluation campaigns as negative controls.
- Sequential accumulation is a statistical improvement only after defining the null, reference sampling, overlap, refresh behavior, and account or group multiplicity. A fixed-window FPR does not imply the same probability of ever flagging an account over months.
- A useful operational verdict is "behavior consistent with extraction, under these alternatives and this benign comparison," with corroborating campaign evidence. "The caller is distilling" requires a stronger basis than broad topics, diversity, or high throughput.

### Gaps

- This note does not inspect TRACE code or verify which existing shadows consume task, account, or sequence features; the parent investigation must map these candidates to current implementation.
- No universal query-only discriminator for training intent is established. If an attacker and a benign evaluator send the same observable transcript, a passive detector has no transcript evidence that separates them.
- The statistical papers do not establish useful detection power when attackers mimic task-matched benign prompts, poison the reference, use real-user relay traffic, or distribute queries below measured contamination levels. Those require explicit empirical tests or a narrower claim.
