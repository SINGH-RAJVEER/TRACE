## Reproduce without changing the reading

From the repository root, create a separate CPU environment using `uv`. The versions below are those recorded in the original audit environment; the repository's own `uv.lock` still governs the ordinary workspace. No GPU, running harness or teacher service is needed. Model weights must already be cached when offline mode is enabled.

```bash
direnv exec . uv venv outputs/mmd-audit/.venv
direnv exec . uv pip install --python outputs/mmd-audit/.venv/bin/python --index-url https://download.pytorch.org/whl/cpu --extra-index-url https://pypi.org/simple --index-strategy unsafe-best-match 'torch==2.15.0+cpu' 'transformers==5.22.1' 'numpy==2.5.4' 'scipy==1.18.1' 'scikit-learn==1.9.1' -e packages/harness
```

Choose a fresh result directory. Embedding caches are deliberately excluded from version control. To reuse an existing cache, set `MMD_AUDIT_CACHE_DIR` to its absolute path. Otherwise, `embed.py` writes the cache into the fresh output directory. Creating the original detector and prefix-free caches took about 35 CPU minutes per variant and produced about 642 MiB in total; allow several GiB for the separate environment and weights as well.

```bash
export MMD_AUDIT_OUTPUT_DIR="$PWD/outputs/mmd-audit-reproduction"
bash readings/mmd-audit-2026-10-30/run.sh embed.py detector
bash readings/mmd-audit-2026-10-30/run.sh reproduce.py
bash readings/mmd-audit-2026-10-30/run.sh diagnose.py detector
bash readings/mmd-audit-2026-10-30/run.sh arithmetic.py
bash readings/mmd-audit-2026-10-30/run.sh volume.py
bash readings/mmd-audit-2026-10-30/run.sh compare.py
bash readings/mmd-audit-2026-10-30/run.sh evasion.py
bash readings/mmd-audit-2026-10-30/run.sh probes.py
bash readings/mmd-audit-2026-10-30/run.sh probe_specialists.py
bash readings/mmd-audit-2026-10-30/run.sh embed.py noprefix
bash readings/mmd-audit-2026-10-30/run.sh diagnose.py noprefix
```

The launcher defaults to offline Hugging Face access and one BLAS/OpenMP thread. Set `HF_HUB_OFFLINE=0` only when downloading the pinned weights is intended. `MMD_AUDIT_PYTHON` selects a different audit interpreter. The scripts read the frozen readings and write results only into the chosen output directory. `compare.py` requires `volume.py` first; `evasion.py` imports the comparison's fitted thresholds.

`role-shift.json` and `mixture-control-frozen.json` preserve auxiliary diagnostic outputs whose standalone producer scripts were not retained. They are not generated by the command sequence above. Repeated deterministic outputs do not constitute independent test populations. The lower-tail and two-sided variants were explored after inspecting attacks and require fresh source-disjoint confirmation before any deployment claim.
