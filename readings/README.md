# Harness readings

These are historical observations, not evidence that the current workspace has completed a new evaluation. [v1](v1/) records AG News and SQuAD detector calibration and replay. [v3](v3/) records a shared gateway calibration, held-out benign replay, and protected campaign results.

A policy that admits every request is an idealized admission reference. It does not imply that every request returns a usable response. Compare actual request outcomes and retain failures, missing attribution, and incomplete runs.

Each version README records its dates, scope, findings, and limitations. Version numbers preserve the identities assigned to the original runs; versions without retained harness readings remain in the archive.
